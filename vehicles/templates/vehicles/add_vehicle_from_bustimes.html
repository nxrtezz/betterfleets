How it works:

  1. Enter a bustimes.org vehicle URL
  2. The system will extract the vehicle slug from the URL
  3. It will call the bustimes.org API to fetch vehicle data
  4. Related objects (operator, vehicle type, livery) will be created if needed
  5. The vehicle will be added to the database and you'll be redirected to edit it

Note: This will check if a vehicle with the same registration already exists to avoid duplicates.
